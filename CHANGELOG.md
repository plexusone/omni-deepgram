## [v0.5.0] - 2026-04-05

### Highlights

- Agent Experience (AX) integration for machine-readable error handling

### Added

- `DeepgramClassifier` implementing `resilience.ErrorClassifier` for Deepgram-specific error classification ([`3f1eb74`](https://github.com/plexusone/omni-deepgram/commit/3f1eb74))
- `ClassifyError()` convenience function to wrap errors with AX metadata ([`3f1eb74`](https://github.com/plexusone/omni-deepgram/commit/3f1eb74))
- Error classification into 8 categories: transient, rate_limit, validation, auth, not_found, server, quota, unknown ([`3f1eb74`](https://github.com/plexusone/omni-deepgram/commit/3f1eb74))

### Changed

- STT provider wraps all errors in `resilience.ProviderError` with classification metadata ([`3f1eb74`](https://github.com/plexusone/omni-deepgram/commit/3f1eb74))
- TTS provider wraps all errors in `resilience.ProviderError` with classification metadata ([`3f1eb74`](https://github.com/plexusone/omni-deepgram/commit/3f1eb74))

### Dependencies

- Requires `github.com/plexusone/omnivoice-core` v0.8.0+ for `resilience` package ([`3f1eb74`](https://github.com/plexusone/omni-deepgram/commit/3f1eb74))

### Tests

- 26 test cases covering all error categories and classification patterns ([`3f1eb74`](https://github.com/plexusone/omni-deepgram/commit/3f1eb74))
